How to Submit Assignments

Guidelines for submitting your 10 CrewAI projects using a Node.js Express backend.

Part 1: Node.js Backend Service

1Create Node.js routes /agent1 through /agent10

The backend routes /agent1, /agent2 … /agent10 match the ten CrewAI projects.

2Use POST routes with a JSON body

Every route must accept a POST request. The input is text only, sent as JSON:

{
  "input": "......"
}

3Return the answer in this JSON format

The endpoint returns an HTTP 200 response with JSON in this exact shape:

{
  "output": "....."
}

4GET requests redirect to the project

When an evaluator opens /agent1 … /agent10 in a web browser (HTTP GET), the server redirects (HTTP 302) directly to the corresponding interactive project interface (e.g. /projects/blog-post-crew).

5Test in Postman

Test every route /agent1 through /agent10 in Postman before submitting.

Part 2: GitHub Repository

6Create a single CrewAI GitHub repo

Your CrewAI multi-agent application lives in its dedicated repository (no AutoGen repository required).

The repository contains the deployed backend service (Node.js/Express), the CrewAI agents service (Python/CrewAI), and the React frontend.

Evaluation: Assignments will be evaluated based on both the GitHub link and the deployed backend link.

Part 3: Submission

Submission rules

  • Submit a .txt file containing the deployed backend link.
  • No leading or trailing spaces around the link.
  • Submit the backend URL only (e.g. https://crewai-server.onrender.com), not the frontend URL.
  • Include the CrewAI GitHub repository link as well.

Example Node.js Express Implementation

server/src/routes/agents.js

import express from 'express';
const app = express();
app.use(express.json());

// GET /agent1 redirects to the interactive frontend page
app.get('/agent1', (req, res) => {
  res.redirect(302, '/projects/blog-post-crew');
});

// POST /agent1 processes text input and returns {"output": "..."}
app.post('/agent1', async (req, res) => {
  const input = req.body?.input;
  if (!input) {
    return res.status(400).json({ error: 'Field "input" is required.' });
  }

  // Execute project 1 (CrewAI Blog Post Crew)
  const output = await runCrewAIAgent(1, input);
  return res.json({ output });
});

// Repeated for /agent2 through /agent10 ...

Run locally

# Terminal 1: CrewAI agents internal service
cd agents && .venv\Scripts\python -m app.main

# Terminal 2: Node.js Express backend server
cd server && npm start

# Terminal 3: Vite React frontend
cd frontend && npm run dev

Pre-Submission Checklist

Verify every item before submitting

  • Postman test verified:
    Method: POST
    Headers: Content-Type: application/json
    Body: {"input": "hello"}
    Response: {"output": "..."} (HTTP 200)
  • All 10 routes covered:
    /agent1, /agent2, /agent3, /agent4, /agent5, /agent6, /agent7, /agent8, /agent9, /agent10.
  • Redirects verified:
    GET /agent1 redirects to /projects/blog-post-crew, etc.
  • GitHub repository:
    CrewAI repository committed and pushed to GitHub with clean instructions.
  • Final file:
    A .txt file containing the live deployed backend URL (e.g. https://crewai-server.onrender.com) and GitHub repository URL with no leading or trailing whitespace.
