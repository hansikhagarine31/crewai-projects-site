05

Customer Support Flow

FlowRouter
Problem

Support tickets arrive mixed together, and each one has to be read, sorted and sent to the right person.

Solution
@start()receive_ticketFills the ticket state
@listen(receive_ticket)categorize_ticketDirect LLM call
@routerroute_by_categoryReturns a label
One label wins
@listen("billing")handle_billingpriority = high
@listen("account_access")handle_accesspriority = high
@listen("other")handle_othertechnical, feature
or_
@listen(or_)resolve_ticketReturns resolution

Free: Gemini free tier, plain Python state, no paid tools

Problem

Auto-generated reports are risky to publish unchecked, but reviewing every word by hand is slow.

Solution

@listen(research)Writing CrewDrafts the report

@routercheck_decisionapproved or revise
One label wins

@listen("revise")Revision CrewThen back to review
